# SpeedFast - Sobrecarga y Sobreescritura

## Descripción

El proyecto representa un sistema básico de pedidos para SpeedFast, utilizando **herencia, polimorfismo, sobrecarga y sobreescritura**.

## Clases

* `Pedido`: clase base.
* `PedidoComida`: pedidos de comida.
* `PedidoEncomienda`: documentos o paquetes.
* `PedidoExpress`: compras express.
* `Main`: ejecución del programa.

## Estructura

```text
src
└── main
    └── java
        ├── app
        │   └── Main.java
        └── model
            ├── Pedido.java
            ├── PedidoComida.java
            ├── PedidoEncomienda.java
            └── PedidoExpress.java
```

## Tecnologías

* Java
* Maven
* IntelliJ IDEA

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Esperar la carga de Maven.
3. Ejecutar `Main.java`.
