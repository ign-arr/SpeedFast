# SpeedFast

Sistema de gestión de pedidos en Java para la empresa SpeedFast.
Desarrollado para las actividades de la Semana 1 y Semana 2.

## Descripción

El proyecto implementa una jerarquía de clases para gestionar distintos tipos de entregas. Utiliza conceptos de Programación Orientada a Objetos como clases abstractas, herencia, sobrecarga y sobrescritura de métodos.

## Estructura

- **app:** Contiene el archivo `Main.java` para la ejecución del programa.
- **model:** Contiene la clase base `Pedido` y sus derivadas (`PedidoComida`, `PedidoEncomienda`, `PedidoExpress`).

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar el archivo `Main.java` ubicado en el paquete `app`.
