# SpeedFast

## Descripción

Sistema básico de gestión de pedidos para SpeedFast.

Incluye pedidos de:

- Comida
- Encomiendas
- Compras Express

## Conceptos aplicados

- Herencia
- Polimorfismo
- Clase abstracta
- Sobrecarga
- Sobreescritura
- Interfaces
- ArrayList

## Funcionalidades

- Asignación de repartidores
- Cálculo de tiempo de entrega
- Despacho de pedidos
- Cancelación de pedidos
- Historial de entregas
